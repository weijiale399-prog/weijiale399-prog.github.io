二、重点短语与什么时候用

Excuse me.

劳驾；打扰一下。想问路、想请别人让一下，或想礼貌地引起注意时使用。例：Excuse me, where is the bus stop?（打扰一下，公交车站在哪里？）
语法句型 固定礼貌表达，整体记忆，不需要自己拆开造句。

Yes?

嗯？ / 什么事？别人叫你时，可以用它表示“我在听，你说吧”。语气要自然，不是每次都翻译成“是的”。
语法句型 简短回应句，省略了完整句子，日常对话中很常见。

Pardon?

请再说一遍？没听清对方的话时使用。语气礼貌。
语法句型 固定疑问表达，用来请求对方重复刚才的话。

Thank you.

谢谢。别人帮助你、给你东西或提供服务时使用。
语法句型 固定感谢表达；也可以说 Thank you very much.（非常感谢。）

🧠

三、句型与语法拆解

Excuse me.

意思：打扰一下 / 劳驾。

怎么用：在提出问题或请求之前，先礼貌地引起对方注意。

Excuse me.（打扰一下。）
语法句型 固定礼貌表达，不按普通“主语 + 谓语”句子分析。
Yes?

意思：嗯？有什么事吗？

怎么用：有人叫你时，表示你已经注意到对方。

A: Excuse me.　B: Yes?（甲：打扰一下。乙：什么事？）
语法句型 简短回应，口语中常省略完整表达。
Thank you (very much).

意思：谢谢（非常感谢）。

拆开看：thank 是“感谢”；you 是“你”。这里的 you 是感谢的对象。

Thank you very much.（非常感谢。）
语法句型 固定感谢表达；very much 用来加强感谢的程度。
本课先掌握这件事：英语交流不只是背单词。像 Excuse me、Pardon、Thank you 这样的整块表达，要连同使用场景一起记。
🎧

四、发音与口语小提示

Excuse me：两个词要连贯读出来，练习时先慢读，再逐渐读自然。注意 excuse 开头是短促的 /ɪ/ 音。
Pardon?：句尾语调通常上扬，表达“没听清，请再说一遍？”
Thank you：thank 的 th 是舌尖轻触上下齿之间发出的气音，不要直接读成 s 或 f。
发音练习顺序：先听标准发音 → 跟读 3 次 → 不看文字说 1 次。重点是清楚、自然，不用一开始就追求很快。

语法句型 固定礼貌开场。

易错提醒：Excuse me 是开口前引起注意；Sorry 多用于道歉。Pardon? 是请对方重复，不是道歉。

三、核心句型：一步一步拆开

Is this your + 名词?

中文：这是你的……吗？

结构：Is（be动词）+ this（这个）+ your（你的）+ 名词？

Is this your book?（这是你的书吗？）
语法句型 一般疑问句：Be动词 + 主语 + 其他部分？这里 this 是主语。
Is this your pen?（这是你的钢笔吗？）
语法句型 同一个句型，只替换最后的名词。
Yes, it is.

中文：是的，它是。

什么时候用：对 Is this…? 作肯定回答。

A: Is this your bag?　B: Yes, it is.（这是你的包吗？是的。）
语法句型 Yes + 主语 + be动词。这里用 it 指代前面提到的物品。
No, it isn't.

中文：不，它不是。

什么时候用：对 Is this…? 作否定回答。

A: Is this your book?　B: No, it isn't.（这是你的书吗？不，它不是。）
语法句型 No + 主语 + be动词 + not。isn't = is not。
This is my + 名词.

中文：这是我的……

注意：陈述句中 this 在前，is 在后。

This is my pen.（这是我的钢笔。）
语法句型 肯定陈述句：This（主语）+ is（be动词）+ my pen（后面的部分）。

四、容易混淆的地方

this 和 it

this：指着眼前的东西说“这个”。
it：用来接着指代已经提到的那个东西。
问句用 this，回答里常用 it。

my 和 your

my：我的。
your：你的 / 你们的。
它们后面都要接名词，例如 my bag、your book。

陈述句和一般疑问句

This is…：这是……（告诉别人）。
Is this…?：这是……吗？（向别人提问）。
把 is 放到 this 前面，就变成提问。

isn't 是什么

isn't = is not，意思是“不是”。
回答时说 No, it isn't.，不要说 No, it is not?。

特别注意：your book 中间不能漏掉名词 book。my / your 不能单独直接放在这里代替“我的 / 你的那个东西”。
🧩

第70课 · When were they there?

was / were 过去式 + at / on / in 时间介词
本课学习目标：学会谈论过去某一天、某个时间或某个季节，人或物在哪里；能把现在的 am / is / are 换成过去的 was / were，并正确使用 at、on、in。
📖

一、先理解本课内容

本课承接前面学过的 There is / are 和 be 动词。本课把时间从“现在”移到“过去”：现在说 They are at the station.（他们在车站），过去就说 They were at the station.（他们当时在车站）。
🧩

二、语法重点详细讲解

1. was / were 是什么？was 和 were 是 be 动词 am / is / are 的过去式。be 动词不表示一个具体动作，而是说明“是谁、是什么、在哪里、处于什么状态”。所以过去说“我在家”“他们很忙”，都要用 was / were。
2. was 和 were 怎么选？I、he、she、it，以及一个人/一个东西这样的单数主语，用 was；you、we、they，以及多个对象这样的复数主语，用 were。注意：you 无论表示你一个人还是你们多人，都用 were。
3. 肯定句怎么说？主语后面放 was / were，再接地点、身份或状态。地点前常有 at、in、on 等介词；状态后面可以接形容词。
4. 一般疑问句怎么变？把 was / were 放到主语前面，句末加问号。回答时也用 was / were：Yes, they were. / No, they weren't. 不需要 do、does 或 did。
5. 否定句怎么变？在 was / were 后面加 not：was not = wasn't；were not = weren't。否定词 not 放在 be 动词后面。
6. When 和 Where 怎么问？When 问时间，Where 问地点。因为句子里是 be 动词过去式，所以疑问词后面直接接 was / were，再接主语。
7. 时间介词 at / on / inat 常用在具体钟点；on 常用在星期和具体日期；in 常用在月份、年份、季节和较长时间段。注意：这是表达时间的用法，不是地点用法。
⌘

三、本课核心句型结构

肯定句：主语 + was / were + 地点 / 身份 / 状态。
否定句：主语 + wasn't / weren't + 其他。
一般疑问句：Was / Were + 主语 + 其他？
When + was / were + 主语？（问时间）
Where + was / were + 主语？（问地点）
at + 钟点；on + 星期 / 日期；in + 月份 / 年份 / 季节。
💬

四、例句逐句拆解

1. I was at home yesterday.

我昨天在家。

语法句型：I 对应 was；yesterday 表示昨天，说明这是过去的情况。
2. They were at the station last night.

他们昨晚在车站。

语法句型：they 是复数主语，所以用 were；at the station 表示在车站。
3. She wasn't at school on Monday.

她星期一不在学校。

语法句型：she 对应 was；否定句在 was 后加 not；星期前用 on。
4. Were you in London in April?

你四月份在伦敦吗？

语法句型：一般疑问句把 were 提前；月份前用 in。
5. When were they there?

他们当时什么时候在那里？

语法句型：When 问时间；were 放在主语 they 前面。
6. Where was your father at six o'clock?

你爸爸六点钟在哪里？

语法句型：Where 问地点；具体钟点前用 at。

第71课 · He's awful!

一般过去时：规则动词、否定句、疑问句
本课学习目标：学会讲过去发生并已经结束的动作；掌握规则动词过去式的拼写变化，以及 did / didn't 后面必须使用动词原形。
📖

一、先理解本课内容

课文围绕某人昨天多次打电话展开。讲述昨天发生的事时，常用 yesterday、the day before yesterday、last night 等过去时间。注意区分：肯定句用过去式；否定句和疑问句借助 did。
🧩

二、语法重点详细讲解

1. 一般过去时表示什么？表示动作或事情发生在过去，而且现在已经结束。比如昨天打电话、上周到达、前天看电视。句子常带 yesterday、last night、last week、two days ago 等过去时间。
2. 规则动词通常怎样变？大多数动词直接加 -ed：answer → answered，watch → watched。以不发音的 e 结尾，通常只加 -d：arrive → arrived。辅音字母 + y 结尾，通常把 y 改成 i 再加 -ed：study → studied。
3. 有些动词要双写最后一个辅音字母部分“辅音-元音-辅音”结尾的重读短动词，变过去式时双写最后一个辅音字母再加 -ed，例如 stop → stopped。不要把所有结尾字母都机械双写。
4. 肯定句结构主语 + 动词过去式 + 其他。主语是 he、she、I 或 they，都用同一个过去式，不像一般现在时那样给第三人称单数加 -s。
5. 否定句结构主语 + didn't + 动词原形。didn't = did not。did 已经表示过去，所以后面的动词必须恢复原形：didn't answer，而不是 didn't answered。
6. 一般疑问句结构Did + 主语 + 动词原形 + 其他？回答可以是 Yes, 主语 + did. 或 No, 主语 + didn't. 这里的 did 是助动词，不翻译成一个单独的“做”。

第72课 · When did you…?

When did... 过去时间提问 + 过去时回答
本课学习目标：熟练询问过去动作发生的时间；分清问句里的 did + 动词原形和回答里的动词过去式。
📖

一、先理解本课内容

这一课的重点不是只背 When did you...?，而是把“提问时间—听懂问题—用过去式回答”连成完整对话。
🧩

二、语法重点详细讲解

1. When 的作用When 意思是“什么时候”，询问动作发生的时间。它可以问过去、现在或将来，但本课重点是过去发生的动作。
2. 为什么用 did？过去时一般疑问句需要 did。When 放在句首后，接 did，再接主语和动词原形：When did you arrive?
3. 为什么 arrive 不加 -ed？因为 did 已经承担了过去时的语法作用，所以问句中的实义动词用原形。不是 When did you arrived?
4. 回答时为什么用 arrived？回答是普通肯定句，没有 did，所以实义动词需要使用过去式：I arrived at seven.
5. 时间放在哪里？常把具体时间放在句尾：I arrived at seven o'clock. 也可以把 yesterday、last Sunday 等时间放句首作强调，但初学阶段先练句尾最稳。
6. 否定回答Did you arrive late? — No, I didn't. 如果想说完整句，可以说 I didn't arrive late. 记住 didn't 后面还是动词原形。
⌘

三、本课核心句型结构

When + did + 主语 + 动词原形？

Did + 主语 + 动词原形？ — Yes, 主语 + did. / No, 主语 + didn't.
特殊疑问句问具体信息；一般疑问句通常回答 Yes / No。
💬

语法句型：telephone 放在 did 后面，保持原形。
4. She telephoned me yesterday afternoon.

她昨天下午给我打了电话。

语法句型：回答用 telephoned，yesterday afternoon 表示昨天下午。
5. When did they leave?

他们什么时候离开的？

语法句型：leave 是原形；它的过去式是 left。
6. They left two hours ago.

他们两小时前离开的。

语法句型：肯定句用 left；two hours ago 表示两小时前。

🧩

二、语法重点详细讲解

1. Do you have any...?用来询问商店有没有某种商品。any 常用于疑问句和否定句：Do you have any shoes?（你们有鞋吗？）We don't have any.（我们没有。）
2. any 在回答中怎样理解？We don't have any. 中 any 代替前面提到的 shoes，避免重复。这里不是 any + 名词，而是 any 单独使用，意思接近“一个也没有/没有这种东西”。

a lot of + 可数名词复数 / 不可数名词。
some 常用于肯定句；any 常用于普通疑问句和否定句。

2. We haven't got much tea.

语法句型：either 放在否定句句尾，表示“也”。

第80课 · I must go to the…

must 表示必须 + 商店名称与购物表达
本课学习目标：学会用 must 表达必须做的事；认识常见商店名称及其所有格形式；能够说清楚必须去哪里、需要买什么。
📖

一、先理解本课内容

第80课承接第79课购物清单：先发现家里缺少什么，再决定必须去哪个商店。表达“必须去”时用 must go to...；商店名称常见 the grocer's、the butcher's、the greengrocer's 等。
🧩

二、语法重点详细讲解

1. must 表示必须must 是情态动词，表示说话人认为某事有必要、必须做。I must go. = 我必须走。它不是一般实义动词。
2. must 后面接什么？must 后面直接接动词原形，不加 to，不加 -s：I must go；She must go。不能说 must to go 或 must goes。
3. must 的人称形式must 不随主语变化：I must、he must、they must。和一般现在时的 have/has 不一样。
4. must 的否定 mustn'tmustn't = must not，表示“不可以、禁止”。它不是“不必”。例如 You mustn't park here. = 你不可以在这里停车。
5. must 的疑问句把 must 放在主语前：Must I go now? 简短回答可以说 Yes, you must. / No, you needn't.（表示不必时可用 needn't；不要把 mustn't 当成不必。）
6. go to + 地点go to the supermarket 表示去超市；go to the butcher's 表示去肉店。注意 home 是特殊用法：go home 通常不加 to。
7. 商店名称中的 'sthe butcher's 原本可以理解为 the butcher's shop；the greengrocer's 是蔬果店；the chemist's 是药店。口语中常省略 shop。
8. need 与 must 的区别need 表示“需要”，重点是缺少某物或有某种需要；must 表示“必须”，重点是必要性或义务。We need some eggs.（我们需要鸡蛋。）I must buy some eggs.（我必须买鸡蛋。）
⌘

三、本课核心句型结构

肯定：主语 + must + 动词原形。
否定：主语 + mustn't + 动词原形。
疑问：Must + 主语 + 动词原形？
must go to + 地点 / 商店。
need + 名词：需要某物；must + 动词原形：必须做某事。
💬

四、例句逐句拆解

1. I must go to the grocer's.

我必须去食品杂货店。

语法句型：must 后面用 go 原形；to 后面接目的地。
2. She must go to the greengrocer's.

她必须去蔬果店。

语法句型：must 不随 she 变成 musts。
3. We must buy some meat.

我们必须买一些肉。

语法句型：must 后面用 buy 原形；some meat 表示一些肉。
4. You mustn't be late.

你不可以迟到。

语法句型：mustn't 表示禁止或不允许。
5. Must I go now?

我现在必须走吗？

语法句型：疑问句把 must 放到主语 I 前面。
6. We need some sugar, so I must go to the shop.

我们需要一些糖，所以我必须去商店。

语法句型：need 后面接名词；must 后面接动词原形 go。
⚠️

五、常见错误对比

常见错误

错误：She must goes.

正确表达

正确：She must go.
must 后面永远接动词原形。

常见错误

正确表达

正确：I must go.
must 后面不加 to。

正确表达

正确：I must go home.
home 作地点副词时，go home 不加 to。
